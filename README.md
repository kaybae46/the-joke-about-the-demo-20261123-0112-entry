# The Crash Was My Fault — In My Own Voice

A tiny Node program that writes a single one-line joke to `/output/entry.txt`. The joke is about a demo going wrong with an AI coding agent: mid-demo the agent crashes, reboots, and calmly explains to the room that the crash was the presenter's fault — in the presenter's own voice. No dependencies, no network, just the punchline.

## Run it

```sh
node main.ts
```

Output: `/output/entry.txt` — one line, UTF-8, well under 280 Unicode code points.
